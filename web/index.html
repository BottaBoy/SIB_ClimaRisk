Methodologie detaillee de calcul

Description technique complete du backend, des interactions entre fichiers, et du statut CLIMADA.

Architecture des fichiers

web/assets/app.js
  -> /api/v1/runs (backend/app/main.py)
  -> pipeline.py
      -> exposure_ingest.py
      -> exposure_disaggregation.py
      -> impact_runner.py
      -> analysis_export.py

scripts/build_guadeloupe_complete_analysis.py
  -> cree web/data/guadeloupe-complete-analysis.json
scripts/build_guadeloupe_wind_maps.py
  -> cree web/data/guadeloupe-wind-maps.json
scripts/build_guadeloupe_water_infra_map.py
  -> cree web/data/guadeloupe-water-infra.geojson

Hazard

  • STORM and STORM_CMCC tropical cyclone hazards (Nadia Bloemendaal datasets).
  • Wind maps use the full 10,000-year NA catalogs currently available on the server.
  • Probabilistic cyclone risk framing for water infrastructure exposure.
  • Frequency normalization is handled on a copy in the backend architecture (idempotent design).

Exposure

  • Reference page uses complete Guadeloupe water+electric infrastructure datasets.
  • Exposure means the set of assets at stake (infrastructures, habitations, etc.).
  • User uploads: CSV/XLSX and GIS formats (GeoJSON/GPKG) are accepted by the API contract.
  • Lines and polygons are disaggregated to points before impact calculation, then reaggregated.

Impact & Dependency

  • MVP production target is the Eberenz 2021 tropical cyclone impact function.
  • Fallback engine uses 4 states (S0/S1/S2/S3), component health, and electricity-to-water propagation.
  • All water assets are conservatively treated as electricity-dependent in this iteration.

Branchement CLIMADA en production

  • Le calcul principal est maintenant branche sur CLIMADA dans `compute_impacts()` avec le moteur `climada_with_interdependency_v1`.
  • Les sorties web/API restent compatibles et sont enrichies (direct/indirect, PML, TVaR, top evenements).
  • La propagation metier electricite -> eau est appliquee en post-traitement prudent apres dommages directs CLIMADA.
  • Le fallback deterministic existe toujours, mais uniquement en mode explicitement active pour debug/continuites d'exploitation.
