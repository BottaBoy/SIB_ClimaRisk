# Instructions Agent - sib-work

## Lecture obligatoire a chaque tache

Avant toute analyse, modification ou deploiement dans ce projet:
1. lire `/home/ubuntu/sib-work/DEPLOIEMENT.md`
2. appliquer cette procedure comme reference operationnelle

## Regle obligatoire apres modification du site

Si la tache modifie le site (fichiers sous `web/`):
- proposer systematiquement le deploiement en fin de tache
- utiliser cette phrase:

`Veux-tu que je fasse le deploiement maintenant (sans commit/push) ?`

## Contraintes

- Ne jamais faire de commit/push sans demande explicite utilisateur.
- Ne jamais deployer sans validation explicite utilisateur.
- Si l'utilisateur demande un deploiement direct, le faire sans reposer la question.
- Utiliser toujours par defaut les methodes natives CLIMADA.
- Lors de la realisation d'un plan, prevenir explicitement lorsqu'une deviation des processus CLIMADA est envisagee.
