# Journalisation_Run_GuaMar

Journal des reruns Guadeloupe / Martinique / Saint-Barthelemy.

Règle: chaque run terminé doit être journalisé automatiquement juste après la génération des artefacts de page.

Le journal brut est stocke dans `docs/Journalisation_Run_GuaMar.jsonl`.
Les identifiants de tracks sont stockes compresses en `zlib+base64` dans le journal brut.
Le pourcentage de tracks communs correspond a `|A ∩ B| / |A|` entre le run courant et le run precedent du meme territoire et du meme alea.
`sampling_spacing_m` vient du JSON de page; `max_points_total` et `max_points_per_feature` viennent du proxy multi-aléas léger utilisé pour la page; `component_light_rerun_active` indique si la page contient un bloc `component_light_rerun`.
